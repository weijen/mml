# Learning Mathematics for Machine Learning

This project creates learning materials to help me understand *Mathematics for Machine Learning* (MML). The aim is to make the book easier for me to learn, starting with Chapter 2: Linear Algebra.

## What I need from these materials

I am building my confidence in mathematics and in reading mathematics in English. The lessons should:

- Use simple English and explain new mathematical words.
- Start with small, concrete examples before formal definitions.
- Show calculations step by step, without skipping the small steps.
- Use interactive diagrams to help me see what the numbers mean.
- Include practice questions with hints and explanations.
- Separate the main ideas from harder details I can return to later.

These materials are a personal reading companion to the book. The goal is understanding, not just memorizing formulas.

## Start learning

Open [chapter-2/index.html](chapter-2/index.html) in a browser. Begin with [the math and English warm-up](chapter-2/00-start.html).

Chapter 2 currently has 13 pages: an overview, a warm-up, 10 lessons, and a practice guide covering all 20 book exercises. The pages work offline, with no installation required.

## Keep the book PDF local

The book PDF must not be uploaded to this repository. `mml-book.pdf` is excluded by `.gitignore`.

Get your own copy from [the authors’ website](https://mml-book.com/). Place it locally at the repository root, beside `chapter-2/`, and name it `mml-book.pdf` to use the lessons’ links to the book. The lessons reference the January 15, 2024 draft; page numbers may differ in other versions.
