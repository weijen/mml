# Mathematics for Machine Learning — reading companion

A simple-English, interactive guide to Chapter 2: Linear Algebra.

## Start reading

Download or clone this repository, then open [chapter-2/index.html](chapter-2/index.html) in your browser. Start with [the math and English warm-up](chapter-2/00-start.html).

The 13 pages include a warm-up, 10 lessons, interactive diagrams, worked examples, and a guide to all 20 chapter exercises. Everything works offline; no installation is needed.

## The book

This repository contains the companion, not the book PDF. Obtain the book from [the authors’ website](https://mml-book.com/). To use the local PDF links, place your copy named `mml-book.pdf` in this repository’s root, beside `chapter-2/`. The companion references the January 15, 2024 draft; other editions may have different page numbers.
