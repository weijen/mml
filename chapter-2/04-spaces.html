LESSON 04 / §2.4

What makes something a vector?

Addition and scaling matter more than arrows.

About 22 minutesBook pp. 35–40 ↗
By the end

You can test a subspace and recognize vectors beyond geometric arrows, while keeping the scalar field and operations explicit.

IN THIS LESSON
START SMALL

One idea for this lesson

A vector space is a collection where addition and scaling follow the usual rules.

First understand a line through zero. The abstract group definition is a second reading task.

How to read the symbols aloud

Read U ⊆ V as: “U is a subset of V.” Every item in U is also in V.

English help · words used in this lesson

First reading: just these three steps

  1. Read the polynomial example as ordinary addition.
  2. Compare a full line with a half-line.
  3. Test whether a set contains zero and stays closed.

You can stop after these steps and the “Pause & predict” question. Return to the formal details when the main idea feels familiar.

A vector is an object with a consistent algebra

An arrow is one model of a vector. A polynomial, an audio sample array, or an image can also be a vector. What matters is that addition and scalar multiplication obey the vector-space rules.

For example, let p(t) = 1 + 2t and q(t) = 3 − t. Then p + q = 4 + t and 2p = 2 + 4t. All remain in the space of polynomials of degree at most 1. Their coordinates relative to (1,t) are (1,2), (3,−1), (4,1), and (2,4).

Closure is necessary, but not the whole definition

Staying in the same set is only the first requirement. The operations must also satisfy the group and scalar rules below. A custom operation that happens to be closed does not automatically make a vector space.

SECOND READING · MORE DETAIL

Why the book introduces groups

A group describes one operation that can be performed and undone consistently. For a set G and an operation ★, require:

PropertyWhat to check
Closurea ★ b stays in G.
Associativity(a ★ b) ★ c = a ★ (b ★ c).
IdentitySome e leaves every element unchanged on either side.
InverseEach a has an element that combines with it to give e on either side.

If a ★ b = b ★ a as well, the group is Abelian. Integers under addition form an Abelian group: the identity is 0 and the inverse of 3 is −3. Nonnegative integers fail because −3 is missing. Nonzero reals under multiplication form an Abelian group with identity 1 and inverse 1/a.

All n × n matrices under multiplication do not form a group: singular matrices lack inverses. The invertible ones form GL(n,ℝ). This is generally non-Abelian for n ≥ 2; GL(1,ℝ) is Abelian.

SECOND READING · MORE DETAIL

Build a vector space on that foundation

A real vector space first needs an Abelian group under addition. That supplies closure, associativity, an additive zero, additive inverses, and commutativity. Scalar multiplication must be closed and satisfy:

λ(u + v) = λu + λv
(λ + μ)v = λv + μv
λ(μv) = (λμ)v
1v = v

These rules justify distributing and regrouping the expressions used throughout the chapter. They imply 0v = 0, λ0 = 0, and (−1)v = −v. The first zero in 0v is a scalar; the output zero is the vector-space zero.

The scalar field matters. Complex numbers form a two-dimensional vector space over ℝ, with basis (1,i), but a one-dimensional space over ℂ. This guide follows the chapter’s real-scalar setting.

Subspaces: smaller worlds with the same rules

A subset U of an existing vector space V inherits most algebraic laws. You only need to show that it contains zero and is closed under addition and arbitrary real scaling. Equivalently, check that U is nonempty and αu + βv ∈ U whenever u,v ∈ U and α,β ∈ ℝ.

Yes: a line through zero

{t(1,2) : t ∈ ℝ}. Adding or scaling changes only t.

No: a shifted line

{(x,y) : y = 2x + 1}. It excludes (0,0).

No: a half-line

{t(1,2) : t ≥ 0}. Negative scaling leaves the set.

Containing zero alone is insufficient: the union of the coordinate axes contains zero, but (1,0) + (0,1) = (1,1) lies on neither axis. Intersections of subspaces are subspaces, because every closure condition holds in each participating space.

Why homogeneous systems always give subspaces

Let U = {x : Ax = 0}. It contains zero. If Au = Av = 0, then A(αu + βv) = αAu + βAv = 0. So all linear combinations stay inside U.

Conversely, every subspace of ℝⁿ can be described by some homogeneous linear system. This connects a geometric description (“a line through zero”) with an algebraic one (“solutions of these equations”).

Pause & predict

Do all polynomials of degree exactly 2 form a vector space?

Give me a hint

Add t² and −t².

Show the reasoning

No: their sum is the zero polynomial, which has no degree 2. Polynomials of degree at most 2, including zero, do form a vector space. A description with a nonlinear-looking parameter also need not fail: in the book’s Exercise 2.9(a), μ³ ranges over every real number.
