LESSON 02 / §2.2

Matrices are machines

Learn the rules by asking what they do.

About 22 minutesBook pp. 22–26 ↗
By the end

You can check shapes, compute products, and distinguish transpose, inverse, and elementwise multiplication.

IN THIS LESSON
START SMALL

One idea for this lesson

A matrix is a table of numbers with a particular calculation rule.

Start with a two-by-two table. You do not need to understand the general summation formula on the first reading.

How to read the symbols aloud

Read A ∈ ℝ²ˣ³ as: “A is a real matrix with two rows and three columns.”

English help · words used in this lesson

First reading: just these three steps

  1. Count rows and columns.
  2. Follow one row-times-column calculation.
  3. Try multiplying a matrix by a two-number vector.

You can stop after these steps and the “Pause & predict” question. Return to the formal details when the main idea feels familiar.

Shape first, arithmetic second

A matrix is a rectangular array. Entry aij is in row i, column j. A 2 × 3 matrix takes a 3-component input and produces a 2-component output. It is helpful to write its job as ℝ³ → ℝ².

Add matrices of the same shape entry by entry. Scale a matrix by scaling every entry. Multiplication has a different rule because it represents the composition of machines.

(m × n)(n × p) → (m × p)

The inner dimensions must match. The outer dimensions give the output shape. For Ax, the shape check is (m × n)(n × 1) = (m × 1).

Where row-times-column comes from

Let A and B be the following machines. To find the first column of AB, feed the first column of B through A. Repeat for the second column.

A = 1201   B = 2013   AB = 4613

Entry (1,2) means “row 1, column 2.” Its value is 1·0 + 2·3 = 6. Here the dot means multiplication.

Show every small step of this product

Top left: 1×2 + 2×1 = 2 + 2 = 4.
Top right: 1×0 + 2×3 = 0 + 6 = 6.
Bottom left: 0×2 + 1×1 = 0 + 1 = 1.
Bottom right: 0×0 + 1×3 = 0 + 3 = 3.

Put these four answers in their matching positions. The result is [[4,6],[1,3]].

The following formula says the same thing for a larger matrix. You may return to it later:

(AB)ij = ∑k=1n aikbkj

The summation sign means “add the following terms over the listed index.” The shared index k runs along row i of A and down column j of B.

Why order matters

ABx means B acts first, then A. For these matrices BA = [[2,4],[1,5]], which differs from AB. A horizontal shear followed by a stretch need not equal the reverse order.

SECOND READING · MORE DETAIL

The essential rules

RuleMeaning / condition
(AB)C = A(BC)Regroup compatible products, but keep the order.
A(B + C) = AB + ACDistribute, with matching shapes.
ImA = AIn = AIdentity has ones on the diagonal and zeros elsewhere.
(AB)ᵀ = BᵀAᵀTranspose reverses product order.
(A + B)ᵀ = Aᵀ + BᵀTranspose distributes over addition.
(AB)⁻¹ = B⁻¹A⁻¹For invertible square A and B; undo the last action first.

Scalar factors can move through a matrix product: λ(AB) = (λA)B = A(λB). But (A + B)⁻¹ generally does not equal A⁻¹ + B⁻¹. There is no general rule that lets you divide by a matrix.

Transpose is a change of layout

Transpose exchanges rows and columns: aij becomes aji. A column vector x becomes a row vector xᵀ. Transposing twice gives the original array.

123456T = 142536

A square matrix is symmetric when Aᵀ = A. Sums of symmetric matrices remain symmetric; products need not, because (AB)ᵀ = BA for symmetric A and B. Their product is symmetric exactly when AB = BA.

For column vectors u,v ∈ ℝⁿ, uᵀv is a scalar, while uvᵀ is an n × n matrix. The bare product uv is not a compatible matrix product except in the scalar case. Elementwise array multiplication is a separate operation, the Hadamard product.

An inverse undoes the machine

A square matrix A is invertible if a matrix A⁻¹ satisfies both AA⁻¹ = I and A⁻¹A = I. “Regular” and “nonsingular” mean invertible. “Singular” means not invertible. A machine that merges distinct inputs cannot have an inverse: it has lost the information needed to recover which input you supplied.

abcd−1 = 1/(ad − bc) d−b−ca   if ad − bc ≠ 0

For A = [[2,1],[1,1]], ad − bc = 1, so A⁻¹ = [[1,−1],[−1,2]]. Multiplying verifies that both products give I. The quantity ad − bc is the 2 × 2 determinant; the general theory comes in Chapter 4.

Pause & predict

A has shape 2 × 3 and B has shape 3 × 4. Which of AB and BA exists?

Give me a hint

Check the neighboring dimensions separately.

Show the reasoning

AB exists and has shape 2 × 4. BA would require 4 = 2, so it is undefined. Do not confuse an undefined product with a zero product.
