Same vector, new coordinates

Derive the basis-change formula instead of memorizing it.

About 30 minutesBook pp. 50–58 ↗
By the end

IN THIS LESSON
START SMALL

One idea for this lesson

The vector stays the same. Its coordinate numbers can change.

An address depends on the reference system. Learn the first numerical example before the general formula.

How to read the symbols aloud

Read [x]ᴮ as: “the coordinates of x in basis B.” Read S⁻¹ as: “S inverse.”

English help · words used in this lesson
coordinate
A coefficient telling you how much of a basis vector to use.
ordered basis
A basis with a specified first vector, second vector, and so on.
basis change
A change in how the same vectors are described.
representation
A way to describe an object using numbers.

First reading: just these three steps

  1. Check 2(1,1) + (1,−1) = (3,1).
  2. Move the basis slider while keeping x fixed.
  3. Trace the numerical example by both routes.

You can stop after these steps and the “Pause & predict” question. Return to the formal details when the main idea feels familiar.

The object and its address are different

Let B be the ordered basis b₁ = (1,1), b₂ = (1,−1). The vector x = (3,1) has B-coordinates (2,1), because 2(1,1) + 1(1,−1) = (3,1).

How did we find the numbers 2 and 1?

Call the unknown coordinates a and b. We need a(1,1) + b(1,−1) = (3,1).

The first components give a + b = 3. The second components give a − b = 1. Add these equations: 2a = 4, so a = 2. Then 2 + b = 3, so b = 1.

The vector is (3,1) in standard coordinates. The list (2,1) tells us how much of each new basis vector to use.

Write [x]B for the coordinate list and PB for the matrix whose columns are the basis vectors in standard coordinates. Then:

x = PB[x]B   and   [x]B = PB⁻¹x

The inverse is valid here because B is a basis of all of ℝⁿ. For a k-dimensional subspace of ℝⁿ with k < n, the basis matrix is rectangular; find coordinates by solving PBα = x within that subspace instead.

Order matters. Swapping b₁ and b₂ swaps the two coordinates. The book uses B for both an ordered basis and, in other contexts, its column matrix; this guide uses PB when the distinction helps.

Coordinate conversion has a direction

If B and D are bases in standard coordinates, the matrix converting D-coordinates to B-coordinates is:

[x]B = PB⁻¹PD[x]D

Read right to left: PD turns the D-address into the actual standard-coordinate vector; PB⁻¹ expresses that vector in B. The columns of the conversion matrix are the D basis vectors expressed in B.

Attach input and output labels

“Change from B to D” can be ambiguous in prose. Write [x]D = Q[x]B before computing Q. This makes the intended direction checkable and prevents an accidental inverse.

SECOND READING · MORE DETAIL

Now change the matrix of a map

Suppose A represents Φ using old input basis B and old output basis C. Let S convert new input coordinates to old input coordinates, and T convert new output coordinates to old output coordinates.

New input→ S →Old input→ A →Old output→ T⁻¹ →New output
Ã = T⁻¹AS

Derivation: xold = Sxnew and yold = Tynew. Substitute these into yold = Axold: Tynew = ASxnew. Multiplying by T⁻¹ gives the result. For an m × n A, S is n × n and T is m × m.

This is Theorem 2.20 in the book. The underlying map Φ has not changed. Only how its inputs and outputs are described has changed.

Work the book’s simplifying example

A = 2112   S = 111-1

The new basis vectors are b₁ = (1,1) and b₂ = (1,−1). Apply A directly: Ab₁ = (3,3) = 3b₁, and Ab₂ = (1,−1) = b₂. In the new coordinates, the machine just multiplies the first coordinate by 3 and leaves the second alone.

S⁻¹ = ½ 111-1   ⇒   S⁻¹AS = 3001

Check it with x = (3,1). Its new coordinates are (2,1). The diagonal matrix produces (6,1); convert back to get 6b₁ + b₂ = (7,5). Directly, A(3,1) = (7,5). Both routes agree.

Chapter 4 will explain how to find useful directions like these systematically. For now, understanding why the coordinates simplify is enough.

SECOND READING · MORE DETAIL

Equivalence versus similarity

Matrices related by Ã = T⁻¹AS are equivalent: input and output bases can change independently. Square matrices related by Ã = S⁻¹AS are similar: use the same change of basis for an endomorphism’s input and output.

Similarity implies equivalence, but the reverse need not hold. For example I and 2I are equivalent, taking S = 2I and T = I, but not similar, since S⁻¹IS = I for every invertible S.

Pause & predict

A maps standard input coordinates to standard output coordinates. Change only the input basis to columns of S. What is the new matrix?

Give me a hint

The output conversion T is the identity.

Show the reasoning

AS. New input coordinates first become standard coordinates through S, then A acts. If only the output basis changes to T, the result is T⁻¹A.
