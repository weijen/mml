Why row operations are legal

Gaussian elimination rewrites a system without changing its solution set. Use the augmented matrix [A | b] so that each operation changes both sides of an equation.

  1. Swap two rows: change the order of the constraints.
  2. Multiply a row by a nonzero scalar: an equivalent equation.
  3. Add a multiple of one row to another: Ri ← Ri + cRj, for i ≠ j.

Each action is reversible. Multiplying a row by zero is forbidden because it destroys information. Arbitrary column operations change the interpretation of the unknowns and are not ordinary row elimination.

A worked example, one operation at a time

We will solve x + 2y − z = 1 and 2x + 5y + z = 5. Predict the next row before stepping forward.

Read the staircase of nonzero entries

A pivot is the first nonzero entry in a nonzero row. In row-echelon form (REF), zero rows lie at the bottom and each pivot is farther right than the pivot above it. This makes back-substitution possible.

Reduced row-echelon form (RREF) adds two requirements: each pivot equals 1, and every other entry in that pivot’s column is zero. In our example, columns 1 and 2 are pivot columns. Variables x and y are basic variables; z is free.

A row [0 0 0 | 5] says 0 = 5: stop, no solution. A row [0 0 0 | 0] contributes no constraint. Only coefficient columns correspond to variables; a pivot in the augmented column signals inconsistency.

One solution, plus changes that keep it a solution

x = -530 + t 7-31   t ∈ ℝ

Setting the free variable to zero gives a particular solution p = (−5,3,0). The direction z = (7,−3,1) solves Az = 0: 7 − 6 − 1 = 0 and 14 − 15 + 1 = 0. Therefore adding any multiple of it leaves the output unchanged.

The general solution

If Ap = b, every solution is p + z with Az = 0. Proof: A(p + z) = b. Conversely, if Ax = b, then A(x − p) = 0. This proves both that the formula works and that it misses no solutions. The solution set is unique; its choice of particular point and spanning directions need not be.

The book’s minus-one trick, unpacked

The trick on pp. 32–33 is a compact way to construct null-space directions from RREF. It is easiest to understand by choosing one free variable at a time.

R = 1203001-1

The equations are x₁ + 2x₂ + 3x₄ = 0 and x₃ − x₄ = 0. Free variables are x₂ and x₄. Choose (x₂,x₄) = (−1,0) to get (2,−1,0,0), and (0,−1) to get (3,0,−1,−1).

R̃ = 12030-100001-1000-1

After removing zero rows, insert a row with −1 at each missing diagonal pivot position. Columns 2 and 4 of this expanded array are exactly those two null-space vectors. Choosing +1 instead simply reverses their signs; either basis works. This expanded array is a reading aid, not an equivalent augmented equation system.

SECOND READING · MORE DETAIL

Compute an inverse by solving several systems

For a square matrix, apply the same row operations to [A | I]. If the left block becomes I, the right block becomes A⁻¹. Each identity column is a different right-hand side, so you are solving all columns of AX = I simultaneously.

[ 1112 | I ] → [ I | 2-1-11 ]

Here subtract row 1 from row 2, then subtract the new row 2 from row 1. If the left block cannot become I, A is singular.

SECOND READING · MORE DETAIL

What changes on a computer?

For hand calculations, elimination reveals structure. In numerical work, pivot selection helps control rounding error. Solving Ax = b directly is generally preferable to explicitly constructing A⁻¹.

If A has independent columns, AᵀA is invertible. For a consistent system, x = (AᵀA)⁻¹Aᵀb is its solution. For an inconsistent system, this formula gives the unique least-squares minimizer instead; it does not make the original equations true. The book discusses this full-column-rank form of the pseudoinverse, not a formula valid for every matrix.

Dense elimination for n × n systems takes arithmetic work proportional to n³. Large structured systems may use iterative solvers. The book sketches x(k+1) = Cx(k) + d; convergence needs suitable C, not an arbitrary choice. The error x(k) − x* and the residual b − Ax(k) are different quantities. Iterative methods and least squares are context here, not prerequisites for the rest of Chapter 2.

Pause & predict

A consistent system has 5 unknowns and 3 pivots. How many free parameters remain?

Give me a hint

Each pivot determines one basic variable.

Show the reasoning

Two. Set each free variable independently; solve for the three basic variables. The solution set is a two-dimensional affine space, even though each solution has five entries.
