When the origin moves

Finish where you began: the geometry of solutions.

IN THIS LESSON
START SMALL

One idea for this lesson

Affine means: do a linear operation, then allow a shift.

A line through zero is a vector subspace. Slide it away from zero and it is still an affine line.

How to read the symbols aloud

Read p + U as: “p plus U.” It means add the same vector p to every vector in U.

English help · words used in this lesson
affine
Allowing a translation of linear structure.
translation
A shift by the same amount and direction.
support point
One point used to locate an affine space.
direction space
The subspace of directions along an affine space.
hyperplane
A space with one fewer dimension than its surrounding space.

First reading: just these three steps

  1. Move the line using the slider.
  2. Check whether it still contains zero.
  3. Compare Ax with Ax + a.

You can stop after these steps and the “Pause & predict” question. Return to the formal details when the main idea feels familiar.

An affine space is a translated subspace

L = p + U = {p + u : u ∈ U}

U is the direction subspace and p is a support point. A line can be written p + td for a nonzero direction d. A plane can be written p + su + tv for independent directions u,v. Its dimension is the dimension of its direction space.

The support point is not unique: any point on L can play that role. The direction subspace is unique, because differences of points in L recover it. L is a vector subspace exactly when it contains zero, equivalently p ∈ U.

SECOND READING · MORE DETAIL

Points can be combined, with one extra condition

For points pᵢ in an affine space, an affine combination ∑αᵢpᵢ stays in the space when ∑αᵢ = 1. To see why, write pᵢ = p + uᵢ. Then ∑αᵢpᵢ = p + ∑αᵢuᵢ. Without the sum-to-one condition, the support point is scaled too.

This is a useful extension of the book’s definition: the midpoint ½p₁ + ½p₂ stays on the line, while p₁ + p₂ need not. Differences of points are direction vectors, so subtracting two solutions removes the offset.

SECOND READING · MORE DETAIL

Linear systems return as affine spaces

If Ax = b is consistent, its solution set is p + ker(A), where Ap = b. Thus it is an affine space of dimension n − rank(A). If b = 0, it is the kernel itself. If the equations contradict each other, the solution set is empty.

A hyperplane in ℝⁿ has dimension n − 1. One scalar equation aᵀx = c with a ≠ 0 defines a hyperplane. A general consistent vector equation Ax = b can have higher codimension; it is a hyperplane only when rank(A) = 1.

Read the rank condition carefully

The broad hyperplane wording in the remark on printed p. 62 needs this qualification. For example, two independent constraints in ℝ³ typically leave a line of dimension 1, not a hyperplane of dimension 2.

For containment, p + U ⊆ q + W exactly when U ⊆ W and p − q ∈ W. The directions must fit, and the support point must lie in the larger affine space.

Affine maps: transform, then translate

f(x) = Ax + a

A is the linear part and a is the translation vector. Since f(0) = a, this map is linear exactly when a = 0. Much ML terminology calls a layer “linear” even when it includes a bias; mathematically its pre-activation map is affine.

If g(y) = By + b, composition gives:

g(f(x)) = B(Ax + a) + b = (BA)x + (Ba + b)

So a composition of affine maps is affine. If A is invertible, the inverse is f⁻¹(y) = A⁻¹(y − a). Invertible affine maps preserve dimension and parallelism, but generally do not preserve lengths or angles. Noninvertible affine maps can collapse lines or planes.

Pause & predict

Is f(x,y) = (x + 2, y − 1) linear? Is it invertible?

Give me a hint

Test the origin. Then try to undo the shift.

Show the reasoning

It is affine, not linear: f(0,0) = (2,−1). It is invertible, with f⁻¹(u,v) = (u−2,v+1). Being reversible does not by itself imply linearity.
