Linear maps preserve combinations

Knowing where the basis vectors go tells us the whole rule.

One idea for this lesson

A linear map changes vectors while respecting addition and scaling.

Think of a machine: give it a vector, and it returns another vector. “Map” here means a rule, not a picture of a country.

How to read the symbols aloud

Read Φ(x) as: “phi of x.” It means the output of the rule Φ when its input is x.

English help · words used in this lesson
map / mapping
A rule that gives one output for each input.
domain
The collection of allowed inputs.
codomain
The stated collection in which outputs live.
injective
Different inputs always give different outputs.
surjective
Every member of the codomain can be reached.
bijective
Both injective and surjective.

First reading: just these three steps

  1. Compare shear, stretch, and collapse in the diagram.
  2. See where the two basic arrows go.
  3. Test whether a rule sends zero to zero.

You can stop after these steps and the “Pause & predict” question. Return to the formal details when the main idea feels familiar.

Linearity is a promise about structure

Φ(αu + βv) = αΦ(u) + βΦ(v)

This must hold for every u,v and every real α,β. It says you get the same answer whether you combine inputs before applying Φ or combine their outputs afterward.

Every matrix map x ↦ Ax is linear because multiplication distributes and respects scaling. Differentiation is linear on an appropriate function space: (αf + βg)′ = αf′ + βg′. Integration over fixed bounds is linear too.

A linear map must send zero to zero. That is a useful rejection test: x ↦ Ax + b with b ≠ 0 is not linear. But passing this test alone does not prove linearity: x ↦ x² sends zero to zero and fails additivity.

Columns record the images of basis vectors

In standard coordinates, x = x₁e₁ + ⋯ + xₙeₙ. Apply linearity:

Φ(x) = x₁Φ(e₁) + ⋯ + xₙΦ(eₙ)

So build A by putting Φ(eⱼ) into column j. That is why a matrix stores everything about a linear map. If Φ(e₁) = (2,1) and Φ(e₂) = (−1,3), then:

A = 2-113   and   Φ(3,2) = 3(2,1) + 2(−1,3) = (4,9)

For arbitrary input basis B and output basis C, the rule becomes: column j is the C-coordinate vector of Φ(bⱼ). This distinction matters in the next lesson.

SECOND READING · MORE DETAIL

One-to-one, onto, and reversible

NameMeaningFor A ∈ ℝm×n
InjectiveDifferent inputs have different outputs.rank A = n
SurjectiveEvery point in the stated codomain is reached.rank A = m
BijectiveBoth; every output has exactly one input.m = n = rank A

The codomain is part of the definition. The map t ↦ (t,0) is injective, but is not onto ℝ². With its codomain restricted to the horizontal axis, it is bijective.

A linear map is also called a homomorphism. A bijective linear map is an isomorphism. A linear map from a space to itself is an endomorphism; if also bijective, an automorphism.

SECOND READING · MORE DETAIL

Why finite-dimensional spaces become arrays

Two finite-dimensional real vector spaces are isomorphic exactly when they have the same dimension. Choosing a basis constructs the isomorphism: send the coefficient list (α₁,…,αₙ) to ∑αᵢbᵢ.

Thus polynomials of degree at most 2 and ℝ³ have the same linear structure. This does not automatically identify their lengths or angles; those require extra structure in Chapter 3.

Composing linear maps gives another linear map. If Φ has matrix A and Ψ has matrix B, with compatible intermediate coordinates, Ψ ∘ Φ has matrix BA. Sums and scalar multiples of maps with the same domain and codomain are also linear. A bijective linear map has a linear inverse.

Pause & predict

Is Φ(x,y) = (x + y, 2x + 2y) injective?

Give me a hint

Can different inputs have the same sum?

Show the reasoning

No. (1,0) and (0,1) both map to (1,2). The difference (1,−1) maps to zero. Its image is the line spanned by (1,2), so it is also not onto ℝ².
