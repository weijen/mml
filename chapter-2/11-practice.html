One practice problem using the whole chapter

Consider the map with matrix A below. Find its rank, a basis for its image, its kernel, the condition for Ax = b to be consistent, and all solutions when b = (3,6).

A = 12-124-2
Hint: what does the second row contribute?

It is twice the first. There is one pivot and two free variables. Every output must have its second component twice its first.

Full worked solution

The rank is 1. The image has basis {(1,2)}, so consistency requires b₂ = 2b₁. The homogeneous equation is x₁ + 2x₂ − x₃ = 0. Set x₂ = s, x₃ = t: the kernel has basis {(-2,1,0),(1,0,1)}.

For b = (3,6), take p = (3,0,0). Every solution is (3−2s+t,s,t). This is an affine plane in ℝ³ with the kernel as its direction space. Its dimension is 3 − 1 = 2. The map is neither injective nor onto ℝ². Changing coordinates cannot change its rank or make it invertible.

Guide to every book exercise

2.1 · Groups with an unfamiliar operation

Printed pp. 64 · Open problem in PDF ↗ · Review lesson

First hint

Rewrite a ★ b + 1 as (a + 1)(b + 1). This converts the operation into ordinary multiplication on nonzero real numbers.

Reasoning / result checks

The identity is 0, and the inverse of a is −a/(a+1). Closure follows because (a+1)(b+1) cannot be zero. Associativity and commutativity follow from multiplication. The equation becomes 4(x+1)² = 16, giving x = 1 or x = −3.

2.2 · Modular arithmetic and groups

Printed pp. 64 · Open problem in PDF ↗ · Review lesson

First hint

Work with residue classes, not chosen integer representatives. Addition has inverse −a modulo n. For multiplication, ask whether a residue has a multiplicative inverse.

Reasoning / result checks

Modulo 5 the nonzero residues have inverses 1↔1, 2↔3, 4↔4. Modulo 8, 2·4 = 0 shows failure of closure on the nonzero residues. For n ≥ 2, prime n makes every nonzero residue coprime to n, and Bézout gives an inverse. A composite n has nonzero factors whose product is 0 modulo n. For n = 1 the nonzero-residue set is empty and is not a group.

2.3 · A matrix group

Printed pp. 64 · Open problem in PDF ↗ · Review lesson

First hint

Denote a matrix by its three parameters (x,y,z), multiply two generic matrices, then solve for the inverse.

Reasoning / result checks

The parameter product is (x+x′, y+y′, z+z′+xy′). Identity is (0,0,0); inverse is (−x,−y,xy−z). Associativity is inherited from matrix multiplication. It is not Abelian: the cross-term xy′ can differ from x′y.

2.4 · Matrix products

Printed pp. 64–65 · Open problem in PDF ↗ · Review lesson

First hint

Write the shape above each factor before doing arithmetic. For every legal product, compute one row-column pair at a time.

Reasoning / result checks

Part (a) is undefined: (3×2)(3×3) has mismatched inner dimensions. Parts (b),(c) give 3×3 arrays; (d) gives 2×2 and (e) gives 4×4. A useful check on (d) is its first entry: 1·0 + 2·1 + 1·2 + 2·5 = 14.

2.5 · General solutions

Printed pp. 65 · Open problem in PDF ↗ · Review lesson

First hint

Reduce [A | b], check consistency, then set one parameter per non-pivot column.

Reasoning / result checks

For each proposed answer p + ∑tᵢzᵢ, verify Ap = b and every Azᵢ = 0. You also need n − rank(A) independent kernel directions to know the answer is complete. In part (b), column 3 is zero, so x₃ must be free if the system is consistent.

2.6 · A sparse system

Printed pp. 65 · Open problem in PDF ↗ · Review lesson

First hint

Columns 1 and 3 are zero. Read the other equations directly before doing unnecessary elimination.

Reasoning / result checks

Set x₁ = s, x₃ = t, x₅ = u. Then x₂ = 2−u, x₄ = −1−u, x₆ = u−1. Thus all solutions are (s,2−u,t,−1−u,u,u−1).

2.7 · A homogeneous equation with normalization

Printed pp. 66 · Open problem in PDF ↗ · Review lesson

First hint

Move 12x to the left to get (A−12I)x = 0. Only after finding this null space impose the sum of the coordinates.

Reasoning / result checks

The third row gives x₂ = 3x₃/2, and the second gives x₁ = 3x₃/2. The sum is 4x₃ = 1. Hence x = (3/8,3/8,1/4). This can be solved with Chapter 2 tools without learning eigenvalues yet.

2.8 · Inverse or singular?

Printed pp. 66 · Open problem in PDF ↗ · Review lesson

First hint

For part (a), inspect a linear relation between rows. For part (b), row-reduce [A | I].

Reasoning / result checks

In (a), row 1 − 2·row 2 + row 3 = 0, so no inverse exists. For any inverse you calculate in (b), verify its product with A is I. The rank test should be completed on the left block, not the entire augmented matrix.

2.9 · Subspaces and misleading parameters

Printed pp. 66 · Open problem in PDF ↗ · Review lesson

First hint

Ask what values each parameter expression can actually take. μ³ ranges over ℝ; λ² ranges only over the nonnegative reals.

Reasoning / result checks

(a) is span{(1,1,1),(0,1,−1)}. (b) is a half-line and fails negative scaling. (c) is a subspace exactly when γ = 0. (d) fails real scalar closure: scaling (0,1,0) by 1/2 leaves the set.

2.10 · Independence

Printed pp. 66 · Open problem in PDF ↗ · Review lesson

First hint

Put the given vectors into columns and look for free variables in Aα = 0.

Reasoning / result checks

In (a), the third vector is 2x₁ − x₂, so dependence holds. In (b), the third coordinate forces α₁ = 0; then the second forces α₂ = 0, and the first forces α₃ = 0. Those vectors are independent.

2.11 · Find combination coefficients

Printed pp. 66 · Open problem in PDF ↗ · Review lesson

First hint

Solve [x₁ x₂ x₃]α = y. The unknowns here are coefficients, not components of y.

Reasoning / result checks

The coefficients are (−6,3,2). Check: −6(1,1,1) + 3(1,2,3) + 2(2,−1,1) = (1,−2,5).

2.12 · Intersect spans

Printed pp. 67 · Open problem in PDF ↗ · Review lesson

First hint

With generator matrices B₁,B₂, solve B₁α = B₂β, or [B₁ −B₂](α,β) = 0.

Reasoning / result checks

Map the resulting parameter solutions through B₁ to obtain actual vectors in the intersection, then remove zero or dependent results. Parameter vectors live in a different space from the intersection itself; returning those coefficient lists is not a basis of U₁ ∩ U₂.

2.13 · Intersect kernels

Printed pp. 67 · Open problem in PDF ↗ · Review lesson

First hint

A vector lies in both kernels exactly when it solves the system obtained by stacking A₁ above A₂.

Reasoning / result checks

Compute dim Uᵢ = 3 − rank(Aᵢ), since the matrices have three columns. Find the intersection from the stacked system, whose solutions also have three entries. This is not the same problem as Exercise 2.14.

2.14 · Intersect images

Printed pp. 67 · Open problem in PDF ↗ · Review lesson

First hint

Now Uᵢ are column spaces. First find bases from original pivot columns, then use the shared-output method of Exercise 2.12.

Reasoning / result checks

These spaces live in ℝ⁴, since the matrices have four rows. Their dimensions equal rank(Aᵢ), not 3 − rank(Aᵢ). Do not stack the matrices as in the kernel exercise: that imposes a different condition.

2.15 · Implicit and parametric descriptions

Printed pp. 67 · Open problem in PDF ↗ · Review lesson

First hint

Substitute (a−b,a+b,a−3b) into x+y−z = 0 to determine which parameters put a point of G into F.

Reasoning / result checks

The condition is a + 3b = 0. Substituting a = −3b gives b(−4,−2,−6), so the intersection is span{(2,1,3)}. F has basis (1,0,1),(0,1,1); G has basis (1,1,1),(−1,1,−3). Both are subspaces.

2.16 · Test maps for linearity

Printed pp. 67–68 · Open problem in PDF ↗ · Review lesson

First hint

For function spaces, apply the algebra of integration or differentiation. For a failure, one counterexample is enough.

Reasoning / result checks

Integration over fixed bounds and differentiation are linear. Cosine is not, since cos(0) = 1. The remaining maps are multiplication by fixed matrices and are linear. The angle in (e) is fixed for a given map.

2.17 · Matrix, image, and kernel together

Printed pp. 68 · Open problem in PDF ↗ · Review lesson

First hint

Read each output expression into one matrix row, then row-reduce the resulting 4×3 matrix.

Reasoning / result checks

The columns are independent: a 3×3 minor formed from the first three rows has determinant 7. Thus rank = 3, ker Φ = {0}, and the three original columns form a basis of its image. The image has dimension 3 inside ℝ⁴, so the map is injective but not onto ℝ⁴.

2.18 · Automorphisms and composition

Printed pp. 68 · Open problem in PDF ↗ · Review lesson

First hint

Use the stated assumption that both maps are automorphisms: both are already bijective.

Reasoning / result checks

Their kernels are {0} and their images are E. Their composition is an automorphism too. All the claimed equalities follow, and {0} ∩ E = {0}. The stronger stated assumptions make this simpler than a general kernel/image composition problem.

2.19 · One map in a new basis

Printed pp. 68 · Open problem in PDF ↗ · Review lesson

First hint

Form S from the listed basis vectors in standard coordinates. The requested new matrix is S⁻¹AS.

Reasoning / result checks

A is invertible (determinant −2), so its kernel is {0} and image is ℝ³. To verify a computed new matrix, check S Ã = AS column by column. This checks the direction of the coordinate change without another inverse.

2.20 · The full coordinate pipeline

Printed pp. 68–69 · Open problem in PDF ↗ · Review lesson

First hint

Keep every coordinate label. If P₁ sends B′ coordinates to B, P₁ = P_B⁻¹P_B′. Here P₂ sends C coordinates to standard coordinates, so P₂ = P_C.

Reasoning / result checks

Add and subtract the two given images to find Φ(b₁) = c₁ + 2c₃ and Φ(b₂) = −c₁ + c₂ − c₃. Thus A = [[1,−1],[0,1],[2,−1]] and A′ = P₂AP₁. For the specified x, [x]_B = (8,9), [Φ(x)]_C = (−1,9,7), and the standard output is (6,−11,12). Both routes must give that same output.

Keep these distinctions straight

TermQuestion it answers
SpanWhat can these vectors build?
IndependenceIs there a redundant ingredient?
BasisWhich ingredients give existence and unique coordinates?
DimensionHow many independent directions does this space have?
RankHow many independent output directions does this map reach?
Kernel / null spaceWhich inputs disappear?
Image / rangeWhich outputs are reachable?
CoordinatesWhich coefficients represent this vector in this ordered basis?
Affine spaceWhat happens when a direction space is translated?

Notation decoder

∀ means “for every”; ∃ means “there exists”; ⊆ means “is a subset of”; ⇔ means “if and only if”; := introduces a definition; ∘ composes functions, rightmost first. A superscript T or ᵀ is a transpose. A superscript −1 on an invertible matrix is its inverse. ker and Im refer to the kernel and image. The book’s rk is written rank in this guide.
