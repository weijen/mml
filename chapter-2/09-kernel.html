What gets through? What disappears?

Image and kernel complete the story of Ax = b.

One idea for this lesson

The image is what can come out. The kernel is what becomes zero.

Write “input space” and “output space” on your paper. Keep the kernel on the input side.

How to read the symbols aloud

Read ker(A) as: “the kernel of A.” Read Im(A) as: “the image of A.”

English help · words used in this lesson

First reading: just these three steps

  1. Find the outputs in the small matrix example.
  2. Solve its zero-output equations.
  3. Check that the two dimensions add up to three.

You can stop after these steps and the “Pause & predict” question. Return to the formal details when the main idea feels familiar.

Two spaces, on two sides of the machine

For A : ℝⁿ → ℝᵐ, the image is the set of reachable outputs, and the kernel is the set of inputs mapped to zero.

Im(A) = {Ax : x ∈ ℝⁿ} ⊆ ℝᵐ
ker(A) = {x ∈ ℝⁿ : Ax = 0} ⊆ ℝⁿ

The image is the span of A’s columns. The kernel records combinations of those columns that cancel. Both are subspaces, by linearity. The notation Φ⁻¹({0}) for a kernel means the preimage of zero, not that an inverse function exists.

Compute both for the same matrix

A = 101011

The first two columns are a basis of ℝ², so Im(A) = ℝ² and rank A = 2. To find the kernel, solve x₁ + x₃ = 0 and x₂ + x₃ = 0. Set x₃ = t:

ker(A) = span{ -1-11 }

The image has dimension 2; the kernel has dimension 1. Notice that the kernel vector has three entries, while each image vector has two. Mixing these ambient spaces is a frequent source of mistakes.

Why the kernel measures ambiguity

If Ax = Ay, subtract to obtain A(x − y) = 0. So two inputs collide exactly when their difference lies in the kernel. This immediately proves:

A is injective ⇔ ker(A) = {0}

For any reachable b and any particular solution p, all inputs producing b form p + ker(A). The same kernel describes the freedom in every consistent right-hand side. Changing b moves the solution set; it does not change its direction space.

SECOND READING · MORE DETAIL

Rank–nullity: an accounting identity

dim ker(A) + dim Im(A) = n

The right side is the input dimension. In elimination language there are r pivot variables and n − r free variables. In mapping language r dimensions of output are reachable and n − r independent input directions vanish.

Why the theorem is true beyond matrices

Choose a basis k₁,…,kd of the kernel and extend it to a basis of the domain by adding v₁,…,vr. The images Φ(vᵢ) span the image because the kᵢ contribute zero. They are independent: a zero combination of their images would put the same combination of vᵢ in the kernel, contradicting independence of the extended basis. Therefore the image has dimension r and the domain has dimension d + r.

When domain and codomain have the same finite dimension, injective, surjective, and bijective become equivalent. When their dimensions differ, those words must be kept separate.

SECOND READING · MORE DETAIL

A connection to machine learning

Think of x as a list of feature weights and Ax as predictions. A nonzero kernel vector z changes weights from x to x + z without changing the predictions. Redundant columns mean the observations cannot distinguish those parameter choices.

This is a statement about identifiability, before probability or optimization enters. A later method may select one of many weight vectors, but the original equations alone cannot tell them apart.

Give me a hint

First take x₃ = 0, then add a kernel vector.

Show the reasoning

A particular solution is (4,5,0). All solutions are (4−t,5−t,t), t ∈ ℝ. Substitution gives (4−t+t,5−t+t) = (4,5). The map is onto ℝ² but not injective.
